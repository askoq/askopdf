AskoPDF Groups User Guide

This guide explains how to create, configure, and use page groups in AskoPDF. Groups help organize a document, provide quick access to specific pages, and allow selected parts of a document to be exported separately.

---

## 1. Creating a Group

Open the navigation panel using the button in the top toolbar, then find the Groups section.

If the document does not contain any groups yet, click **Create first group**.

To create additional groups, click the **"+"** button next to the Groups section title.

---

## 2. General

The General tab in the Create Group window contains the following settings:

 **Group Name** - enter a name for the group. This field is required, so the group cannot be created while it is empty. The maximum length is 50 characters.
 **Identifier (Icon)** - select a symbol or emoji that will appear next to the group name in the navigation panel.

## 3. Appearance

The Appearance tab lets you customize how the group looks:

 **Coloring Type** - choose Solid for a single color or Gradient for a gradient.
 **Color Palette** - select colors from the available presets or configure them manually using the color picker.
 When using a gradient, the primary and secondary colors can be configured separately.
 **Navigation Panel Color** - sets the color used for the navigation panel and the current page indicator while the group is active.

## 4. Pages

Open the Pages tab to add and configure pages for the group:

 **Adding Pages** - enter a single page number or a page range. For example, `3-6` adds pages 3 through 6.
 **Rename Pages** - each page can be given a custom name of up to 100 characters. The custom name will appear in the navigation panel instead of the default page number.
 **Sorting** - the order of pages within the group can be changed.
 Once the group is configured, click Create Group to save it.

## 5. Working with Groups

After a group has been created, the following options become available:

 **Quick Jump** - quickly opens a selected page in the document. The drop-down menu can be opened using the button on the group card in the navigation panel.
 **Editing** - group settings can be changed using the pencil icon.
 **Export to PDF** - while editing a group, its pages can be exported as a separate PDF file.
 **Deletion** - a group can be removed using the trash icon.
 **Group Sorting** - the order of groups in the navigation panel can be changed.
 When a group is selected, the interface colors and icons automatically update to match its settings.
